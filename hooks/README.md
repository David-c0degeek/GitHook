# Git Hooks

Place executable hook scripts in this folder using standard Git hook names, e.g.:

- `pre-commit`
- `commit-msg`
- `pre-push`
- `prepare-commit-msg`

On Windows, hooks are typically shell scripts (`#!/bin/sh`) executed by Git Bash.
Make sure each file has no `.sh` extension and starts with a proper shebang.

Install with `..\install.ps1` (see repo root).
